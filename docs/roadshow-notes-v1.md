# 04题 单页路演讲述提纲

作者：WeiR-h · 研究v1.2 · 工具0.3.0 · 2026年10月14日

本提纲配合唯一一页PPT使用，按20分钟准备。官网未说明20分钟是否含问答，正式排练建议主体16分钟，预留4分钟；未获允许时不打开第二页、视频或工具演示。

## 0至2分钟 原生问题

“我想弄清楚，数据中心完成同样的供电任务，钠电如果更贵，究竟要凭什么抵消差价？”研究把购买服务能力转为可复算的经济边界，价格、装机数量、运行和更换必须连起来。

## 2至4分钟 题设和证据

官方是15,000次、−30℃正常充放电。共同适用对象未澄清，主模型暂按双方共同条件。新增实际产品规格和政府中标价，用于目录选型与采购背景；长期现金流保留显式假设。任丘价格已含PCS等，只描述4小时电站采购。昆宇Na柜的工作下限是−20℃，不能把−40℃存储温度当成−30℃运行证明。

## 4至8分钟 主图和需量反例

介绍1MW、2MWh/日、15分钟备用、20年、5%折现的统一任务。两类系统的性能和价格相同，则费用相同；这不是钠电落败，而是对照组校核。

从曲线左端＋43.65万元讲起。充电也会增加购电峰值。在本例平坦谷价的8小时窗口里，摊平补电不增加能量费，把峰值降到1,279.1kW；需量40元假设下，仍为−123.31万元。指明40元不是实际电价，代表日每月出现是简化。10.46元是本条件的回本分界，不是行业统一门槛。

这项改进属于运营策略，双方都能采用。不要把共同调度收益算成钠材料的收益。

## 8至11分钟 右侧短时备电

右上规格比较：昆宇同厂LFP/Na的15分钟功率为232/121kW，按原表条件1MW对应5/9柜。其他费用相同且柜价边界一致时，Na单柜报价低于LFP的55.56%，才可让这组配置首购柜价更低。这里未计UPS转换、EOL降额、额外冗余及通道；更未证明−30℃可用。这个例子解释为什么相同“最大6C”或更低的每kWh单价不能直接决定任务总成本。

备用补充算例：保护1MW、15分钟，需要250kWh交流备用。模型0.5C和4C假设对应2928和407kWh；3.6C是简化功率与能量门槛。台达5柜各200kW虽合计1MW，但那是10分钟BOL规格，额定总能量201.5kWh，忽略损耗也不够15分钟。实际选型必须使用对应时长和EOL曲线。

## 11至13分钟 持续共建与研究修正

右下共建入口：把报价、功率曲线、独立复算、现场计费和使用反馈做成五类任务。认领者提交来源、模型版本和结论影响；另一署名者逐项复核，通过或要求补充。旧结论与修订继续留痕，纠错和不利证据也能推进研究。

当前实现本地资料交换与复核流程，姓名检查不证明真实独立身份。工具未接入1836审核，实际参与与确认仍由平台及参与者完成。收益分配预演按假设池和手工登记项目积分计算，不支付资金。

## 13至16分钟 交付与可以推翻结论的数据

交付是可运行的比较工具、能量账本、现金流、采购分界、11个场景、432格分析及本地共建工作台。输入改动后必须重新运行，导出结果始终附带对应输入。任务不满足时拦截采购胜负；纯备用LCOS为空，改用年化保障费用。

72项自动检查包含经济模型47项及共建流程25项，另有10项资料算术核对。它们检验计算和流程规则；真实产品、合作及经营结果需要实际证据。

把业主储能经济性、工具经营收入与贡献分配分别核算；模型NPV不成为服务收入。第一项商业验证面向一位业主或集成商，记录报告是否帮助识别不可行配置或重复计价。结束时给出可认领入口：同任务报价、低温曲线和使用反馈，取得证据后继续修正边界。

## 预备问答

**为什么输入还有假设？** 已取得实际规格和最终中标价格，但还没有本项目同温度、同EOL和同供货范围的有效报价。规格已用于目录初筛，中标价已用于采购背景；每个字段按自己的证据范围进入计算。

**为什么加40元需量费？** 这是压力测试。实际用电合同可能按容量、合同需量或实际最大需量，可能有折扣和门槛；正式判断必须代入当期地区与合同规则。

**最小峰值就是最优吗？** 本例充电电价平坦，固定补电总量的平均功率给出下界，均分达到下界。其他电价和月度负荷条件需要联合优化，当前两策略不构成普遍最优证明。

**纯备用负NPV说明不该买UPS吗？** 模型未计停电保障收益，负值只表示备用系统有成本；采购是否值得要看可靠性、必要性及损失避免。不能用套利NPV否定必要的保障。

**钠电低温更好，是不是已经可以胜出？** 先核验实际低温充放电能力及同供货报价，再和有温控的可行LFP路线比较。低温优势只有变成减少装机、温控耗电或更换成本后，才进入经济账。

**真实报价到底找到了什么？** 找到了任丘政府原始最终中标金额和范围，Na约1035.41、LFP 518元/kWh。它们是4小时成套设备价格，尚缺昆宇等厂商对本项目的正式含税报价。不能把该单位价格直接拼到本模型电池、PCS、温控的分项成本。

研究及图表来源见v1.2研究PDF；外部事实链接放在PPT讲者备注。正式20分钟安排以组委会通知为准，提交前按唯一一页PPT排练。

寿命问题的补充问答：每天2MWh的年测试等效循环为233.6次，15年日历假设先于15000次耗尽；LFP6000次假设也同年换电。次数换算不代表可保寿命，真实日历质保仍需厂商资料。
