# 04题 钠电经济试验台v0.3与研究v1.2发布

作者：WeiR-h · 2026年10月14日

我在04题想解决的问题是：让数据中心完成同样的供电和备电任务，钠电的寿命、低温或倍率优势，究竟在什么条件下能够抵消采购与运维成本？这版交付包括钠电经济试验台v0.3、13页研究v1.2和一页路演。经济模型保持v0.2，新增可追溯的共建工作台，便于后续报价、复算和实际使用反馈持续进入研究。

## 三个可以复算的结果

第一，充电可能增加需量费用。采用双方相同的演示参数：1MW负荷、每天交付2MWh、预留15分钟备用、20年项目期、5%折现率；往返效率90%，日历寿命15年。不计需量费用时，双方净现值均为＋43.65万元。在平价充电窗口均分补电，将购电峰值由2,001.3kW降至1,279.1kW；但加入假设40元/kW·月的实际峰值需量费后，净现值仍降至−123.31万元。该数值是条件算例，40元并非已核实的当地电价；这项调度改进对两类电池均适用。

第二，短时备电要同时核对功率与能量。昆宇公开资料中，[LFP CFS80085U](https://www.cospowers.com/products/info/97/1619.html)和[Na CNS80050U](https://www.cospowers.com/products/info/136/1623.html)的15分钟功率分别为232kW和121kW。只按目录工况，1MW需5柜和9柜；在相同供货范围、其他费用相同时，钠电单柜价须低于LFP的55.56%，才能降低这组柜数的首购柜价。公开工作温度下限为0℃和−20℃，因此这条初筛不能当作−30℃、寿命终点或交流侧可用性的证明。

第三，循环次数须与日历寿命共同分析。本例年测试等效循环233.6次，15,000次的次数换算为64.21年，而15年日历假设先触发换电。64.21年不是产品寿命预测，循环次数优势需要进入实际使用强度与质保边界后重新计算。

## 产品与价格证据怎样进入研究

任丘4小时储能项目的政府最终中标公告提供了可核对的历史价格：[钠电40MWh、41,416,220元](https://szj.hebei.gov.cn/hbggfwpt/jydt/003001/003001002/003001002004/20260915/db2166c9-a5c5-48e9-b6ba-bbcfc2670499.html)，复算1,035.41元/kWh；[LFP 360MWh、186,480,000元](https://szj.hebei.gov.cn/hbggfwpt/jydt/003001/003001002/003001002004/20260915/f9176493-3534-4e30-b3bf-8f74662fbc51.html)，复算518元/kWh。其成套范围包含PCS、BMS、消防和热管理等，规模及用途也与AIDC短时备电不同。这些价格保留为历史证据，没有填入电池单价后重复叠加设备费用。本任务的同工况配对报价仍待取得。

## 将证据修正变成持续共建

v0.3开放五类问题：同任务配对报价、15分钟低温功率、独立复算、真实月度负荷与计费、实际使用反馈。每项都有验收条件；提交需带来源、模型版本、结论影响和分享许可，由不同署名者逐项复核。修订和更正保留历史，退回补充的旧贡献积分退出本地分配预演。

储能经济账、工具经营账和项目积分分别记录。模型净现值属于储能项目评价；工具服务的实际收入与费用另行登记，待发生事项确认发生并保留凭据后才计入结余。项目收益按假设池与手工登记积分占比试算，正式身份、积分和收益由1836确认。本地工作台尚未接入平台审核或结算；署名检查也不证明真实独立身份。

已完成72项模型与共建流程检查、10项产品价格算术校核及14份原始资料完整性校验；桌面与手机交互、资料恢复和便携包解压运行均已验证。演练参与者与金额已归档，当前实际外部共建贡献和经营收入均为0。源码采用MIT许可，第三方资料保留原有权利。

希望将选型分析、证据复核和持续更新沉淀为1836中可复用的服务。欢迎AIDC业主、集成商、厂商及复算参与者一起补齐这五类证据，特别是两份相同任务的报价与一次真实独立复核。后续将持续记录证据如何改变结论、实际服务是否发生，以及经1836确认的贡献与收益。[04题项目](https://1836.online/projects/cmujvb96f000z3jo188jx0xjp)
