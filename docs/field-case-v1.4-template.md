# 首个现场数据案例的研究记录

作者：WeiR-h

状态：研究v1.4待填模板，尚未完成现场研究。当前正式研究为v1.3，工具0.3.4，模型0.2.0。内置样例仅验证软件，不填入下列实际证据栏。

## 资料来源及允许使用范围

待记录：提供者或可引用来源、采集时间、原始文件校验值、负荷与电价的计量边界、时间粒度、单位、允许本地使用或公开摘要的明确范围。仅负荷与电价有来源时，产品性能、寿命及报价继续保留原假设标识。

## 质量检查

待记录：当地日期范围、记录行数、完整日数量、缺失小时、重复时刻、异常数值、无效时间、非整小时及乱序情况。首批统一到Asia/Shanghai，仅使用完整整小时日期；资料不完整时不补零、不自动平均为结算峰值。

## 基线与日期选择

待记录：原场景JSON及模型版本、完整可用日概况、所选日期及原因。默认选择最早完整日，另选日期需说明理由；保留所有可用日，避免只呈现最有利样本。

## 更新结果与剩余假设

待记录：前后逐时输入差异，交付、备用、购电峰值、充电费、辅助用电和避免购电费；附逐时能量账。不从一个或少数样本日直接推算实际全年收益。若继续作20年条件模拟，须另行标明代表日重复及费用、寿命等假设。

## 复核与社区发布

先在共建工作台认领并提交证据，再从逐时资料页面关联回放，最后由不同署名者核对并给出意见。已通过的证据若补入新计算，先更正并重新提交。记录只能表明本地流程状态，真实独立身份与正式积分需外部确认。

仅在实际数据到位、检查通过且分享范围明确后，发布现场研究更新。社区摘要不得包含仅本地资料的来源、日期、输入或数值。当前没有为现场研究生成完成凭据。
